# 02 — UX-карта пути (DRAFT v0)

> Идём от момента пользователя, а не от компонента. Для каждого шага: цель → критерий → что сейчас (гипотеза, проверить).

| # | Момент | Цель | Критерий | Сейчас ? |
|---|---|---|---|---|
| 1 | Узнал (сайт/пост/README) | Понять, что это и зачем | ≤30 сек до «понял» | не проверено |
| 2 | Скачал и поставил | Одно действие, без вопросов | ≤2 мин до запущенной платформы | `kb-create` (Go, CLI/wizard) |
| 3 | Онбординг | App ведёт за руку и открывает Studio | без командной строки | нет App-оболочки |
| 4 | Добавил первый проект | `+ Add project`, сервисы поднялись сами | ≤1 мин | `kb init` + ручной `kb-dev start` с `--config`/`--net-offset` |
| 5 | **Первая польза** | Плагин коммитов работает на проекте сразу; рядом — «создай свой плагин» | ≤5 мин с момента установки | не спроектировано |
| 6 | Повседневная работа | Переключение проектов, статусы, логи в UI | ноль команд | несколько CLI-шагов на проект |
| 7 | Расширение | Плагин/адаптер на проект в один клик | ≤30 сек | marketplace через CLI |
| 8 | Обновление | Платформу и плагины обновить и откатить | проекты не ломаются, откат в один шаг | `kb-create update/rollback` |
| 9 | Сбой | Понятно, что упало и как чинить | причина + действие в UI | `doctor`, логи через CLI |

## Персоны

- **Одиночка-разработчик** (сейчас): десятки проектов, платформа — фон.
- **Команда** (облако): общий деплой, доступы, общие плагины/адаптеры. ?
- **Автор плагина/адаптера**: пишет, тестирует, публикует. ?
