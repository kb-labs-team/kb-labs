Install `kb-create`, bootstrap a workspace, and run your first command.

## 1. Install the launcher

```bash
curl -fsSL https://kblabs.ru/install.sh | sh
```

Downloads the correct binary for your platform and installs it to `~/.local/bin`. On macOS and Linux. Windows support is coming.

## 2. Bootstrap your project

```bash
kb-create my-project
```

Runs the interactive wizard: picks a package manager, configures the platform directory, and sets up `.kb/kb.config.jsonc` with sane defaults. When it finishes you have a ready workspace.

To use the declarative scenario engine during the migration cutover:

```bash
kb-create my-project --engine
```

The Human terminal flow and Agent JSON flow share the same scenario state,
validation, compatibility resolution, and installation plan. CI should use
the deterministic direct path instead of a scenario:

```bash
kb-create install --plugins=release --platform ./ci-platform
```

## 3. Start services

```bash
cd my-project
kb-dev start
```

Starts the core services: REST API, Workflow Daemon, Gateway. Check that everything is alive:

```bash
kb-create status
```

## 4. Run your first command

```bash
# See all available commands
kb --help

# Generate a commit plan from staged changes (works without LLM — falls back to heuristics)
kb commit commit --dry-run

# List installed plugins
kb marketplace plugins list
```

**Services won't start:**

```bash

kb-dev start --force   # kill port conflicts and retry
```
