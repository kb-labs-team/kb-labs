## Установка плагина в проект

Выполните команду из каталога проекта, указав точную версию:

```bash
kb marketplace install @kb-labs/commit@1.2.3
```

Проект хранит точную версию, целостность tarball, тип источника и состояние плагина в `.kb/marketplace.lock` схемы v3. В lock-файле нет машинного пути или времени установки. Сам пакет устанавливается в общее хранилище машины. Команда не меняет `package.json`, lock-файл пакетного менеджера или `node_modules`. Добавьте marketplace lock в git вместе с проектом. Если обнаружен lock-файл v2, выполните `kb marketplace sync`, чтобы создать его заново.

## Разработка локального плагина

Создайте плагин в проекте, соберите его и привяжите entry-пакет относительным путём:

```bash
kb scaffold run plugin my-plugin
cd .kb/plugins/my-plugin
pnpm install
pnpm -w build
cd ../../..
kb marketplace plugins add --link .kb/plugins/my-plugin
kb my-plugin hello
```

Команда link записывает локальный пакет в `.kb/marketplace.lock`. Scaffold только создаёт файлы и не регистрирует пакет автоматически.

Команды `kb marketplace plugins disable <package>` и `kb marketplace plugins enable <package>` выключают и включают плагин для проекта. `kb marketplace uninstall <package>` удаляет его pin.

## Установка и привязка адаптера

Сначала установите адаптер в граф пакетов платформы, затем привяжите его к слоту текущего проекта:

```bash
kb marketplace install @kb-labs/adapters-fs@1.2.3 --scope platform
kb adapter bind storage @kb-labs/adapters-fs
```

Команда bind записывает `platform.adapters.storage` в конфигурацию платформы. Параметры адаптера настраиваются на уровне платформы командой `kb config set --scope platform platform.adapterOptions.storage '<json-value>`. Все проекты используют эти настройки. В Studio на странице **Plugins** выбранного проекта можно устанавливать, включать, выключать и удалять плагины.

Привязка отклоняется, если пакет отсутствует в marketplace lock платформы или не распознан как адаптер. В таком случае установите адаптер командой `kb marketplace install … --scope platform`.
